## 2.7 双形态（2026-10-10 重新接回）

内置数据被清空后双形态无从显示，故改成**条目自带**：编辑人形时填「主形态名称 / 第二形态名称 + 第二形态六维数值」，保存为 `e.formLabel` / `e.form2 = { label, vals }`。`fvOf()` 优先读条目自带，其次才回退到内置 `FORM_DATA`（按名字匹配）。卡上出现「主表现值 / 第二形态」按钮，切换只改对比度；总分与账本双列并排。**雷达标签每态各出一套**（放在各自 `.f0`/`.f1` 组里），切换时由 CSS 显隐——所以档位文字会跟着形态变。

## 2.8 派生数据必须随处重算（2026-10-10 修复）

改成手动保存后 `save()` 只标脏（不再落盘），而 `syncLetters()` 挂在 `persist()` 上 → **在编辑弹窗里改数值后，字母档/总分/梯队不会重算**，出现「速度 80 却显示 S」这类陈旧档位。修法：`markDirty()` 内先 `syncLetters()`（拖动顶点那条路本来就有），并在初始化时补一次 `syncLetters()`，保证首屏与数值一致。

## 2.11 空卡（待填）语义（2026-10-10）

**症状**：编辑模式里「对比图形」看着失效——其实两边都是刚内置的空卡（六维全 0），多边形缩成一个点，图上只剩网格。

**修法**：新增 `isBlank(e)`（六维全 0 即空卡）：
- `cmpOptions()` 把空卡排除在「对比对象」之外；全为空时提示「暂无可对比对象：先给某个人形填数值」；
- 「全体平均」`__avg` 与 `dimRankInfo()` 的排名同样只在**非空卡**里统计；
- 空卡卡面：总分显示 `—`、梯队与雷达档位字显示**待填**（弱色），账本每维也是 `— 待填`；
- `ladderHTML()` 空卡不进梯队分组。

## 3. 关键约定（别踩）

- **权重必须按 DIMS 索引取**：`WEIGHTS` 与 `DIMS` 必须同序（自检 14 盯着）。
- **存档键 `gfl2-sixaxis-v5`**：换键＝换一份干净存档；旧键列在 `LEGACY_KEYS`，页面会提示「彻底删除旧存档」。
- **改内置数据必须改 `DATA_VERSION`**，否则浏览器不会提示更新。
- **不要留 100 截断**：数值上限 200，>100 即 ULTRA（自检 13）。
- **字母档＝12.5 分带、同分必同档**；**总分＝六维加权**（自检 07／08／09）。
- **素体＝型号的纯函数**：`frameBaseline` 里型号→分值，同型号必须同分（自检 11）。
- **拖动只在单序列雷达上**（普通卡片与编辑弹窗）；双形态卡是两条折线，不参与拖动。
- **页面内置数据不会自动跟着 JSON 变**，改完要手动同步（自检 02–04 盯着）。
- **排版参数集中在 `LAYOUT`（作者第四版：R100 70、网格 7 圈、网格亮度 .25、100 环 .6、无轴无线无描边、填充 .6、标签偏移 8、维度名 10／描边 .4、档位 10／ULTRA 11／描边 .6、卡片 318/0/30/20）。**顶点圆点与档位弧已整体删除**（作者 2026-10-10 定）。
- **雷达标签固定两条环带**（位置不随数值移动，结构上不可能压字）：维度名贴 100 环**内**沿、朝圆心排；档位字贴 100 环**外**沿、朝外排；两者都加深色描边（`paint-order:stroke`），压在色块上也读得清。实测极端值六条轴零重叠。
- **卡片不做装饰**：去掉切角／顶部横线／右上角折，也去掉了拖动顶点的 hover 提示环（只留 cursor:grab）。
- **页面不放说明文案**：口径、沿革、依据只写在 JSON 与 `_work/剧情证据与评分依据.md` 里，界面保持干净。
